# KAM Overview

## What is KAM?
KAM stands for Key Account Manager.

A Key Account Manager manages clients. One KAM can handle many clients.

## What Does KAM Do?
Every day, KAMs record how many containers they received from their clients.

- **Sent containers**: Tracked in the Transit Plan (not here)
- **Received containers**: Tracked here in KAM section

## How It Works

At the end of each day:
1. KAM opens the Client page
2. KAM sees all their clients
3. KAM clicks on a client name
4. KAM enters how many containers they received
5. KAM saves the data

## Menu Pages

### Client Page
- Shows clients that need data entry for the selected date
- If a client already has data entered for that date, they won't appear in the list
- Shows how many clients are pending (need data) and how many are done
- Click client name to enter details

### Inventory Details Page
- Shows container details for selected client 
- Enter opening stock, dispatch, and returned amounts
- Closing stock is calculated automatically
- Save button saves the data

### Inventory Listing Page
- View historical data
- Filter by date range
- Filter by client
- See dispatch and returned statistics

## Simple Workflow

```
1. Open Client page
2. Select date (usually today)
3. See list of clients that need data entry
4. Click on a client
5. Enter container numbers
6. Click Save
7. That client disappears from the list (they're done!)
8. Move to next client
9. Repeat until all clients are done
```

## Important Points

- Data is saved automatically as you type
- If you refresh the page, your data is still there
- Empty fields become zero (0)
- You can see how many clients are done vs pending
